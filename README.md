# StudentCourseManagement

A simple Student Course Management Web API built with **ASP.NET Core 8**, **Entity Framework Core**, and **Microsoft SQL Server**, following the principles of **Clean Architecture**.

The project demonstrates a layered backend architecture with separation of concerns between the API, application/business logic, domain entities, and infrastructure/database access.

---

## Tech Stack

- **.NET 8 / ASP.NET Core Web API**
- **C#**
- **Entity Framework Core 8**
- **Microsoft SQL Server**
- **Database First approach**
- **LINQ**
- **Dependency Injection**
- **Repository Pattern**
- **DTOs**
- **Clean Architecture**

---
